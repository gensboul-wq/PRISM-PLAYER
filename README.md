# 🎬 PRISM Player

**PRISM** se yon lektè mizik ak videyo modèn, konplètman fonksyonnèl nan navigatè wèb ou — san okenn sèvè, san okenn abònman.

> 🌐 **Jwe kounye a** : [https://nonw.github.io/prism-player](https://nonw.github.io/prism-player)

---

## ✨ Karakteristik

| Fonksyon | Deskripsyon |
|----------|-------------|
| 🎵 **Lekti mizik & videyo** | MP3, MP4, WAV, FLAC, OGG, AAC, M4A, Opus, WebM, MKV, MOV, AVI |
| 📁 **Dosye & Fichye** | Ouvri yon dosye antyè oswa chwazi fichye yo youn pa youn |
| 📂 **Playlist** | Bibliyotèk, Favori, ak playlist pwòp ou |
| 🎛 **Equalizè 8 bann** | 60Hz → 14kHz ak vizyalizasyon an tan reyèl |
| 🌊 **Vizyalizasyon** | Ring, Bars, Wave, Orb |
| ⚡ **Vitès & Tonalite** | Varye vitès lekti a ak chanje tonalite a |
| 🔁 **Repete** | Dezaktive / Tout playlist / Yon sèl tras |
| 🌍 **7 lang** | Kreyòl, Français, English, Español, 中文, हिन्दी, Русский |
| 📱 **Mobil & Desktop** | Responsive, PWA-ready, touch gestures |
| 🔗 **Pataje** | WhatsApp, Telegram, Twitter/X, Facebook |

---

## 🚀 Kijan pou itilize

### Sou entènèt (pi fasil)
1. Ale sou lyen an
2. Klike **"Chwazi Fichye"** oswa **"Ouvri Dosye"**
3. Chwazi mizik/videyo ou yo
4. Jwe !

### Sou odyatè (Android APK)
1. Telechaje APK la nan [Releases](https://github.com/nonw/prism-player/releases)
2. Enstale l
3. Li mache san entènèt — fichye yo rete sou aparèy ou a

### Sou Desktop
1. Klike sou lyen an
2. Pwa **F11** pou plen ekran
3. Itilize **Espas** pou play/pause, **← →** pou seek, **↑ ↓** pou chanje tras

---

## ⌨️ Raccourcis klavye

| Tou | Aksyon |
|-----|--------|
| `Espace` | Play / Pause |
| `←` / `→` | Retounen / Avanse 5s |
| `↑` / `↓` | Tras anvan / Pwochen tras |
| `M` | Muet |
| `F` | Plen ekran |
| `L` | Chanje mòd repete |

## 🛠️ Devlopman lokal

```bash
git clone https://github.com/nonw/prism-player.git
cd prism-player
# Ouvri index.html nan navigatè ou
```

Pa gen okenn depandans, pa gen okenn `npm install`. Se yon fichye HTML sèlman.

---

## 🏗️ Konstri APK (Android Studio)

Si ou vle konstri APK ou pwòp ou :

```bash
cd android/
# Ouvri pwojè a nan Android Studio
# Klike "Build → Build Bundle(s) / APK(s) → Build APK(s)"
```
